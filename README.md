# Kraken levels

Калькулятор лестницы покупок Кракена до нуля: вложения нарастающим итогом, средняя цена, просадка по шагам, учёт лота с тенью, ручные суммы на уровнях цены, доход при развороте и возврате к первому уровню (инвест-доля и поэтапная продажа торговой части отдельно по каждой покупке).
Открыть: https://abornevai.github.io/Kraken-levels/
