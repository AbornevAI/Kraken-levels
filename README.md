# Kraken levels

Калькулятор лестницы покупок Кракена до нуля: вложения нарастающим итогом, средняя цена, просадка по шагам, учёт лота и ручные суммы на уровнях.

## Версия 2

Лестница от бюджета риска: точка нуля, вероятности дна по пяти зонам, цель роста, фьючерсы с ГО и переносом, ручные суммы на уровнях.
